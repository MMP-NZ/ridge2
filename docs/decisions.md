| 2026-09-15 | The measured figure is **advisory only and must never flow into a quote total unconfirmed**. | 2026-09-15 | LINZ Building Outlines are **roof outlines, not ground footprints** — eaves are already included, so no overhang allowance is added. Roof area is `footprint / cos(pitch)`, which is exact for gables, hips, cross-hips and L-shapes alike provided one pitch is shared; it breaks on mixed pitches, dormers, lean-tos and mansards | Confirmed in LINZ's own data dictionary ("a 2D representation of the roof outline"). Getting this backwards matters: a cadastral or OSM wall-line source *would* need ~450-600 mm added all round, which is +13% to +18% on a 200 m² house, so the correction is right or wrong by ±15% depending purely on the source |
| 2026-09-15 | Polygon area will use **spherical excess with the local Gaussian radius of curvature** (~30 lines, no dependency), not `@turf/area`, `proj4`/NZTM2000, or planar Web Mercator | Measured against exact 200 m² test polygons at NZ latitudes: local-radius spherical excess is exact to 0.00%, turf's mean-sphere constant drifts to −0.26% at Invercargill, NZTM2000's grid scale factor is a systematic −0.08% to +0.4% bias, and **uncorrected Web Mercator is 56-110% wrong** at NZ latitudes — never compute area in the tile projection. The only new dependency this feature needs is `sharp`, for compositing tiles and the outline overlay |
